# AIO Converter

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed: Electron + TypeScript, plain HTML/CSS, Vite, electron-builder NSIS. Windows 11 x64 desktop only.

## Users
Windows users converting personal or work files in mixed batches without uploading them.

## Product Purpose
Optional online workspace saves public video/audio links using yt-dlp and bundled Deno. No browser cookies, account sign-in, DRM or live streams. MP4/MKV/WebM/MOV video; MP3/M4A/WAV/FLAC/Opus/OGG audio. Download queue is session-local; cancellation removes partial files.

One installed desktop application converts common images, audio, video, Office documents, PDFs, ebooks and archives offline.

## Operating Context
Public free application, MIT application source. Full offline installer includes conversion engines and runtime. No installed Office or PATH dependencies.

## Capabilities and Constraints
One mixed-file queue, compatible target choices, per-file options, batch application, cancellation, retry and output reveal. Preserve originals and avoid overwrites. Session-local queue; preferences only persist. Explicit supported conversion pairs. Exclude OCR, PDF layout reconstruction, encrypted inputs, DRM, CAD/3D, proprietary projects, AI features.

## Brand Commitments
Name: AIO Converter. Apple-inspired precision and responsiveness, neutral surfaces, blue accent, system typography, subtle translucent toolbar, light/dark/system themes. Native Windows window controls. Calm and direct product copy.

## Evidence on Hand
VERT browser snapshot and partial static REA investigation, plus official product documentation for UniConverter, Movavi, NCH and CoolUtils. These are workflow references, not measured performance claims or copied implementation.

## Product Principles
- Files stay local.
- Only advertise tested conversions.
- Preserve inputs; publish complete outputs only.
- Show actionable failures per file.

## Accessibility & Inclusion
Keyboard operation, visible focus, screen-reader job announcements, high contrast, reduced motion and reduced transparency. Desktop resizing and Windows text scaling.
